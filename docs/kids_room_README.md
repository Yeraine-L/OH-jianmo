# 儿童房间场景文档

## 1. 场景概述

这是一个基于MuJoCo物理引擎的儿童房间场景，设计用于机械臂整理、拿取和摆放物品的模拟实验。场景包含了真实儿童房间的主要元素，包括休息区、学习区、存储区和游戏区，并配备了两台机械臂用于执行整理任务。

## 2. 房间规格

- **房间尺寸**：10m × 12m × 3.5m
- **地板材质**：木质地板，带有装饰性图案
- **墙壁材质**：彩色墙壁，带有窗户和装饰画
- **照明系统**：多角度柔和照明，包括天花板灯、环境光和定向光

## 3. 功能区域

### 3.1 休息区

位于房间北部，包含：

- **现代床**：木质床架，配有床垫、两个枕头和毛毯
- **床头柜**：两张木质床头柜，各配有一盏台灯
- **休息区地毯**：浅色地毯，覆盖整个休息区
- **大型衣柜**：木质衣柜，带有双开门和内部搁板，靠北墙放置

### 3.2 学习区

位于房间东部，包含：

- **现代书桌**：木质书桌，配有键盘、鼠标和显示器
- **人体工学椅**：舒适的办公椅
- **文具**：笔架、笔记本、铅笔和橡皮擦等
- **两个书架**：位于书桌邻近的墙角区域，摆满了各种书籍

### 3.3 存储区

位于房间西南部，包含：

- **大型衣柜**：带有装饰性花瓶
- **玩具架**：两个金属玩具架，用于存放玩具
- **储物箱**：三个彩色储物箱
- **装饰植物**：增添房间生气

### 3.4 游戏区

位于房间东南部，包含：

- **爬爬垫**：柔软的爬爬垫，上面散落着各种玩具
- **滑梯**：小型塑料滑梯
- **积木桌**：配有积木块
- **儿童沙发**：小型舒适沙发
- **丰富的玩具**：包括球类、积木、毛绒玩具、汽车玩具等

## 4. 机械臂系统

场景中配备了两台相同规格的六自由度机械臂，每台机械臂都带有两指夹爪：

### 4.1 机械臂规格

- **类型**：六自由度工业机械臂
- **工作空间**：覆盖整个房间
- **负载能力**：能够处理场景中的所有玩具和物品
- **夹爪类型**：两指平行夹爪，开合范围0-8cm

### 4.2 机械臂位置

- **机械臂1**：位于房间中央偏上位置 (5, 5, 3.0)
- **机械臂2**：位于游戏区附近 (2, 9, 3.0)

### 4.3 控制方式

机械臂可以通过MuJoCo的actuator系统进行控制，包括：

- 关节位置控制（位置型执行器）
- 夹爪开合控制（电机型执行器）

## 7. 使用说明

### 7.1 加载场景

使用MuJoCo的Python绑定或命令行工具加载场景：

```python
import mujoco
# 加载场景
model = mujoco.MjModel.from_xml_path('scenes/kids_room_mujoco.1.26.xml')
data = mujoco.MjData(model)
```

### 7.2 控制机械臂

通过设置执行器的控制值来控制机械臂：

```python
# 控制机械臂1的肩关节
mujoco.mj_set actuator, data.ctrl, 0, shoulder_angle
# 控制机械臂1的夹爪
mujoco.mj_set actuator, data.ctrl, 6, grip_open_amount
```

### 7.3 观察场景

场景中包含多个site和geom，可以通过它们来观察场景状态：

```python
# 获取机械臂1末端执行器位置
end_effector_pos = data.site_xpos[model.site('ee_site').id]
# 获取某个玩具的位置
ball_pos = data.geom_xpos[model.geom('ball_01').id]
```

## 8. 实验用途

这个场景设计用于以下实验：

1. **机械臂物品整理**：机械臂整理书桌上的文具、书架上的书籍或爬爬垫上的玩具
2. **物品分类**：将不同类型的玩具分类放置到不同的储物容器中
3. **路径规划**：机械臂在复杂环境中的路径规划和避障
4. **抓取策略**：不同形状和重量物品的抓取策略研究
5. **多机械臂协作**：两台机械臂协同完成整理任务

## 9. 场景特点

1. **真实物理模拟**：使用MuJoCo的高级物理引擎，模拟真实的物体碰撞和动力学
2. **丰富的物品**：包含多种形状、大小和重量的物品，适合各种抓取实验
3. **详细的场景设计**：真实的房间布局和家具设计，提供沉浸式的模拟环境
4. **可扩展**：可以方便地添加新的物品、家具或机械臂
5. **高性能**：优化的模型设计，确保模拟的实时性

## 10. 扩展建议

1. **添加更多物品**：可以根据实验需求添加更多类型的玩具和物品
2. **修改机械臂**：可以替换为其他类型的机械臂或末端执行器
3. **添加传感器**：可以添加视觉传感器（如摄像头）或触觉传感器
4. **创建任务脚本**：可以编写Python脚本，定义特定的整理任务和评估指标
5. **修改场景布局**：可以根据实验需求调整房间布局和家具位置

## 11. 注意事项

1. **初始状态**：场景加载时，所有物品都处于初始位置，爬爬垫上的玩具是散放状态
2. **物理参数**：所有物品都有真实的质量和物理属性，抓取时需要考虑这些因素
3. **碰撞检测**：机械臂和物品之间的碰撞会被正确检测和处理
4. **控制精度**：机械臂的控制精度取决于执行器的参数设置
5. **模拟速度**：可以通过调整MuJoCo的timestep参数来平衡模拟精度和速度
